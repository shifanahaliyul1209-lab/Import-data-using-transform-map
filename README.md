# Import Data Using Transform Maps (Spreadsheet)

**Submitted by:** S. Afrina

## Project Description

This project demonstrates how to import data into ServiceNow using Transform Maps and a spreadsheet. The project covers the process of importing spreadsheet data, mapping source fields to target fields, and transforming the data into the required ServiceNow table.
